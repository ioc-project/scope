# SCOPE UI

The web dashboard of **SCOPE**: it browses applications, inspects sessions (execution graphs,
agent conversations, reasoning paths, cost and latency metrics), and monitors live topology and
semantic groups.

The full documentation, which covers the tech stack, local development, environment variables,
feature flags, the project structure and the production build, is in
[`docs/platform/ui.md`](../docs/platform/ui/index.md), and published with the rest of the
[SCOPE documentation](https://ioc-project.github.io/scope/platform/ui/).

```bash
yarn install
yarn dev
```
